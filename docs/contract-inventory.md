# Contract inventory: loop / validate pipeline rules

Scope: the loop/validate skill families ([#64](https://github.com/richkuo/rk-skills/issues/64)) plus the plan producers and consumers that feed them.

Each row names a shared rule, its owner, the consumers that must state it, the shared semantics, and the divergence it allows. The owner file holds the full rule.

## How to update a shared rule

Edit every consumer listed for the row in the same change (no generator exists for `SKILL.md` prose, except the pr-review format copies: edit only the skill's `## Review contract`, then run `bun bin/sync-pr-review.mjs --write`), and record an intentional divergence in the row.
